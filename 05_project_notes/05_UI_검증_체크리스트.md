# UI/동작 검증 체크리스트 (Codex 재작업 QA)

## 기초 화면

- [ ] ZIP 압축 해제 후 `02_current_html/aftermarket_decision_board.html` 로컬 오프라인 실행 가능 (기존 참고본).
- [ ] 최종 파일도 `file://` 직접 열기 또는 정적 서버 방식에서 주요 기능 동작.
- [ ] 첫 로딩 시 초기 **추천 선택이 있어도 확정 0개**로 표기.
- [ ] 20개 세부 선택과 5개 범위 확인(C-1~C-5)이 별도 그룹으로 표시.
- [ ] 전체 대상 화면 중 신규 정규장 코스피+코스닥 차트가 별도 탐색 가능.

## 숫자·의미 일관성

- [ ] A-4: 전일 10,000원, 정규장 11,000원, 애프터 10,800원 예시가 전일대비 **+800/+8.00%** vs 정규장 대비 **-200/-1.82%**로 전환.
- [ ] B-6: 사용자의 시안처럼 동일 종목의 양쪽 패널에는 각각 **전일 종가 대비** 등락/등락률을 표시. 서로 다른 종목 독립 모드일 때 **두 종목간의 등락률을 계산하지 않음**.
- [ ] A-5: 누적 거래량과 애프터 거래량 순위가 다르게 나오며, 표/차트/순위의 범위 라벨이 일치.
- [ ] A-6: 재계산 기준을 바꾸면 시가총액 순위가 바뀌고 왜 바뀌었는지 설명이 나타남.
- [ ] A-2: 자동 리스트에서 거래불가 종목 제외. B-4 특징주 별도 처리 옵션은 독립.
- [ ] A-3: 애프터 미체결 종목의 대체 종가에 상태 표기가 연결. 숫자가 '오후 체결가'로 둔갑하지 않음.
- [ ] A-7: 20:10 이후 최종가 유지/정규장 종가 복귀를 선택하면 숫자와 '기준시점' 라벨이 모두 변함.
- [ ] B-1: 누적 통계와 15:30 값 보존은 별도. '애프터 단독 투자자 통계'라고 잘못 표현하지 않음.
- [ ] B-2: 업종지수는 오후 미산출 사실 표시, '정규장 15:30 종가' 라벨 유지.
- [ ] B-5: 전용/통합 2종 차트, 15:30~16:00 공백, 18:00 조회 시 시간축, 20:00 조회 시 시간축을 구분.
- [ ] 긴 종목명: 자간 축소 또는 정책 구현 검토가 실제 예시에서 드러남.

## 체크·회신 워크플로

- [ ] 선택지만 변경하면 즉시 미리보기가 갱신되지만 **확정**으로 자동 전환되지 않음.
- [ ] 확정→선택 변경 시 확정 자동 해제.
- [ ] 씬별 영향보기에서 하나의 설정이 영향을 주는 씬 목록을 표시.
- [ ] 각 질문 메모 및 C-1~C-5 상태/메모 저장·복원.
- [ ] JSON 내보내기/가져오기 후 결정·확정·메모가 동일하게 복원.
- [ ] 회신 TXT에 이미 요청된 사항/새 선택/개발사 추가 확인이 서로 혼동되지 않게 표기.
- [ ] 인쇄 시 제어 버튼 숨김, 회신 본문이 읽기 쉬움.
