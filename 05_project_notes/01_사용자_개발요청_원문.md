   - 긴 종목명 자간 축소
4) 라인그래프 2씬
   - 애프터마켓 시간 전용(16:00 ~ 20:00)
   - 정규장 + 애프터마켓 (09:00 ~ 20:00) 통합, 공백구간 실선 또는 음영 처리
   - 기존 고정 시간축 대신 조회 시점까지 표시 가능한지 확인 필요(기존 정규장에도 적용 가능한지)

## 사용자가 요청한 HTML의 목적

> 이걸 누구나 보기 좋게 확인 요청 사항과 씬에 맞게 반영된 버전이랄까? 어떤 결정을 하면 어떻게 화면이 나온다 이런 예를 보여주는 HTML로 만들어줘. 바로 체크할 수 있게. 그러니까 이렇게 결정하면 이런 영향이 있고, 화면에 이렇게 나온다를 보여주면 됨.

## 별도 업로드한 이미지의 시안 내용

- `01_종목비교_정규장VS애프터.png`: 정규장 종가 VS 애프터 현재가 비교, 같은 화면에 양쪽 패널. 각 패널에 종목명, 해당 가격, 등락가, 등락률. 이미지에는 같은 종목명(엘앤에프)이 보이지만 설명에는 'A종목명(정규장 데이터)', 'B종목명(애프터마켓 데이터)', '한 화면에 2종목'으로 적혀 있어 **좌우 종목 선택 독립 여부 미확정**.
- `02_신규5단_시가총액_상승.png`: 시가총액, 상승 기준 상위종목 5단 레이아웃; 코스피/코스닥 선택; 종목명/현재가/등락가/등락률/거래량/거래대금.
- `03_신규5단_하락.png`: 하락 기준 상위종목 5단 레이아웃; 표시 항목은 위와 동일.
- `04_정규장_코스피코스닥통합차트.png`: **정규장** 코스피·코스닥 지수를 한 화면에 배치하는 신규 통합 라인그래프. 애프터마켓 지수 차트로 해석하지 말 것.
