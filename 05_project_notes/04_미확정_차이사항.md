## 추가 판단이 필요한 사항

- **B-6 좌우 독립 종목:** 시안 텍스트는 A종목/B종목으로 나뉘지만 그림에는 동일한 엘앤에프가 나타남. 각각 독립 선택 가능한지 확인. 서로 다른 종목은 정규장 대비 차액/등락률 계산을 넣지 말 것.
- **A-4 등락률:** 개발사 제안은 거래소 제공 전일 종가 대비. 시안의 각 패널 등락가/등락률과 일치. 신규 화면의 '정규장 종가 대비 애프터 변화'는 별도 표시 기능으로 분리.
- **A-5 거래량:** 원 요청의 `금일 누적`은 **투자자별 매매동향 3종**에 명시된 사항. 종목 시세/상위 리스트 거래량도 정규장+애프터 누적할지는 선택이 필요.
- **A-6 시가총액:** 원 요청에는 신규 5단 `시가총액` 정렬만 있고 정규장/애프터 가격 중 어떤 기준인지는 불명확.
- **A-3/B-6.2 미체결:** 가격 대체/빈칸/상태 라벨이 시청자에게 다른 의미를 전달함.
- **A-7 종료 후:** 20:00 이후 ~ 다음날 09:00 직전 유지/복귀 선택 필요. 실제 기준일, 체결없음과 마지막가 처리 등 edge case 확인 필요.
- **B-2 업종지수:** 개발사 씬 ID 11은 원 사용자가 집계한 기존 10종 분류에 명시적으로 매핑되지 않음.
- **B-4 특징주:** 수동 지정 종목과 자동 검색 목록의 거래불가 처리 기준을 동일하게 강제할지 선택 필요.
- **원 첨부 PDF:** '첨부2', '첨부3' 원본 PDF는 없음. 스크린샷만으로 PDF 페이지 전체 또는 원문 텍스트를 복원했다고 표시하면 안 됨.
- **신규 씬 번호:** 사용자 문구의 '11~13씬'과 5단 3종+비교 1종 수량(4종)이 불일치. 씬 식별자 발주 문구 확정 필요.

## 업체 문의에 대한 회신 원칙

- **이미 요구된 내용**: '기존 요청대로 반영 바랍니다' + 특정 씬/그림을 지정해 설명.
- **결정이 필요한 내용**: 선택 A/B와 그 화면상 영향·시청자 혼동 가능성을 보여준 후 현업 승인 기록.
- **개발 범위 질문**: 구현 가능 여부·추가 견적·운영 조건 등을 개발사에 질의하고 '검토 중'으로 표기.
- 그동안 **개발사 제안 = 현업 확정**으로 간주하지 않는다.
