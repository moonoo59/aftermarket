# Codex 작업 지시 — SBS Biz 애프터마켓 요구사항 결정 HTML 재구현

## 목표

사용자가 업로드한 개발요청 원문·PPTX·화면 시안·개발사 확인서를 근거로, 방송 현업 담당자도 복잡한 설명 없이 각 확인사항에 답할 수 있는 **인터랙티브 의사결정 웹페이지**를 개선/재구현한다.

**핵심 사용자 흐름:** `확인사항 선택 → A안/B안 선택 → 영향을 받는 씬 표시 → CG 스타일의 예시 화면이 즉시 변화 → 의미·운영 영향·추가 개발사항 설명 → 선택 확정/해제 → 최종 회신 정리 및 복사/다운로드`.

## 기본 요구사항 (Must)

1. **서로 다른 성격의 정보를 구별**: `현업 개발요청에 이미 포함됨`, `개발사 추가 결정 요청`, `개발사 구현 가능 여부/범위 확인`, `검토안`, `최종 확정`의 상태를 구별한다.
2. **확인서 내용 누락 금지**: 공통 A-1~A-7 및 씬별 B-1~B-6을 포함하고, 하위 질문까지 분리해 선택한다. 기존 HTML에는 20개 세부 결정 항목이 있다. 관련 씬을 연결한다.
3. **선택별 시각 효과**: 한 항목의 선택을 바꾸면 대표 CG 화면이 자동으로 바뀌어야 한다. 숫자가 달라지는 경우 비교 기준(전일 종가, 당일 정규장 종가, 누적 거래량, 애프터 거래량 등)을 명확히 붙인다. 화면뿐 아니라 '방송 운영 영향'과 '개발 추가 확인'을 함께 보여준다.
4. **씬 중심 탐색**: 씬 14 시세표, 10 특징주, 9 상위종목, 1 라인차트, 7·17·15 매매동향, 11 업종지수(대응 범위 확인 필요), 신규 5단 3종, 신규 비교 씬, 신규 정규장 코스피·코스닥 통합 그래프 등을 탐색하고 각 씬에 영향을 주는 확인사항을 조회할 수 있어야 한다.
5. **원본 시안 대조**: 요청 이미지 4장을 확대해서 볼 수 있게 하되, 모의 구현 화면과 원본 시안을 구별한다. 원본 이미지의 실제 숫자/레이아웃을 출처 없는 실시간 수치처럼 표시하지 않는다.
6. **확정 프로세스**: 초깃값이 있어도 미확정. 사용자가 직접 '확정'해야 확정 카운트 증가. 이후 선택 변경 시 기존 확정은 해제. 결정별 메모 기록. 범위/모순 확인 5건 별도 상태 관리.
7. **결과 내보내기**: 개발사 회신용 텍스트(번호, 항목, 선택, 영향, 메모, 확정 여부, 미확정 항목 별도), JSON 내보내기/가져오기, 인쇄 친화적인 요약. 현업 담당자에게 공유해도 읽기 쉬운 문장.
8. **오프라인 동작**: 로컬에서 더블클릭으로 열 수 있는 HTML. 외부 서버/API/폰트 의존 없이 주 동작 가능. 작업 소스는 분리해도 되지만 최종 배포용 단일 HTML을 별도로 제공.
9. **반응형/접근성**: 데스크톱 중심이며 좁은 모바일 화면에도 가로 잘림 없이 보기. 라디오/버튼의 키보드 사용, 충분한 색 대비, 색만으로 등락 설명하지 않기.
10. **기준 자료에 없는 부분을 임의로 확정하지 말 것**: 추천/검토안과 이미 요청된 사항을 구분하고, 개발사 답변이 필요한 범위는 '미확정'으로 표기.

## 반드시 지켜야 하는 업무 요구사항

- 기존 10종: 매매동향(바차트·테이블·일자별 테이블) 3, 시세표 1, 2~5단 종목 리스트(일봉 포함) 4, 애프터 전용/통합 라인차트 2.
- 신규 애프터: 시가총액·상승률·하락률 기준 5단 리스트 **3씬** (각 코스피/코스닥 선택), 정규장 종가 vs 애프터 현재가 **2종목을 한 화면에 보이는** 비교 **1씬**.
- 신규 정규장: **코스피+코스닥 통합 라인그래프 1씬**. 이를 애프터 전용 종목 차트와 혼동하지 말 것.
- 비교 화면은 원본 시안상 좌우 패널 모두 **전일 종가 대비 등락가/등락률**이 있음. 왼쪽과 오른쪽 종목이 각각 선택되는지 여부는 추가 확인 필요(시안 설명 A/B와 이미지 같은 종목 표시의 차이). 서로 다른 종목 간 상승/하락률을 계산하면 안 됨.
- 매매동향은 **금일 누적**, 장 시간대별 범례 노출. '애프터마켓만의 투자자 통계'라고 라벨링하지 않는다. 선물은 정규장 값 유지 제안을 별도로 구분.
- 애프터 가능 종목 Y만 시세표/자동 리스트에 표시한다는 요청은 첨부1에 존재. 특징주(운영자 수동 선택)의 거래불가 처리 방식은 미확정.
- 시세표·종목 리스트의 **긴 종목명 자간 축소** 요청을 유지. 줄임/약칭은 원 요구와 차이가 있으니 대안으로만 제시.
- 라인차트는 오후 전용 **16:00~20:00**, 하루 통합 **09:00~20:00** **모두 요청**. 정규장과 오후 사이 **15:30~16:00 공백**은 실선/음영 중 선택 또는 병기. 조회한 현재 시각까지만 시간축 표현이 가능한지, 기존 정규장에도 적용 가능한지 질문을 반드시 표시한다.
- 신규 5단은 시총/상승/하락 3종. 시가총액 기준 재계산(A-6), 거래량·거래대금 기준(A-5)이 바뀌면 순위/수치가 바뀌어야 한다.

## 기존 HTML 활용 지침

- `../02_current_html/aftermarket_decision_board.html`은 이미 카드·선택지·CG 화면 미리보기·씬별 보기·범위 확인·회신 정리·로컬 저장 등을 갖춘 **작동 참고본**이다.
- 기존 HTML의 초기 선택과 샘플 숫자를 확정된 정책으로 오인하지 말 것.
- 버그가 있다면 고치고, 필요 시 데이터 모델과 렌더링을 재구조화한다. UI 외관을 보기 좋게 다듬되 **원본 화면 컨셉과 선택에 따른 실제 의미 변화**를 우선한다.
- 디자인만 바꾸는 작업이 아니며, 선택 ↔ 영향을 받는 모든 씬 ↔ 결과 회신 사이의 데이터 일관성이 핵심이다.

## 필수 검증 시나리오

- A-4 전일 대비 ↔ 정규장 종가 대비 전환 시 가상 종목 10,000→11,000→10,800원이라면 오후 등락이 **+8.00% ↔ -1.82%**로 달라져야 함. 비교 기준 라벨도 함께 변화.
- A-5 누적 ↔ 애프터만 변경 시 거래량 상위 종목 순위가 달라져야 함. 합산값은 두 세션 합, 단독값은 애프터 체결분만.
- A-2 거래불가 제외/포함, A-3 미체결 표현, B-4 수동 지정 특징주 유지/제외는 각각 별개이며 모순 없이 적용.
- 20:10에 A-7 최종가 유지/종가 복귀 선택 시 숫자·시각·기준 라벨이 함께 변화.
- B-5 오후/통합 차트 둘 다 시각화 가능하며 통합 그래프는 공백 구간 표시. '현재시간까지만' 요청은 검토 대상과 구현 가능 여부를 분리.
- B-6 좌우 독립 종목이라면 종목 간 등락 계산을 금지. 같은 종목일 때만 **정규장 종가 대비 애프터 변화**를 별도로 계산 가능.
- 신규 정규장 코스피·코스닥 통합 그래프를 독립 씬으로 유지.
- 모든 항목 선택 변경→확정 무효화, 저장→재열기 복원, JSON 왕복, 내보낸 회신에서 미확정이 명확히 표시되는지 점검.

## 결과물

1. 수정 가능한 소스 코드와 구성 설명.
2. 최종 오프라인 실행용 **단일 HTML**.
3. 변경 내용/미결 항목 목록을 적은 `CHANGELOG.md`.
4. 데스크톱/모바일/결정 선택 전후 화면 검증 자료.
5. 누락·모순 없이 회신하는 텍스트/JSON 내보내기 기능.
